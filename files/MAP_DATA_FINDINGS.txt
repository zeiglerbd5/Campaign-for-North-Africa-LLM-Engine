HEX GRID PARAMETERS FROM VASSAL buildFile.xml:
-----------------------------------------------
The map uses a ZonedGrid with 6 hex zones (Malta + Maps A-E) plus holding boxes.
All hex zones share the same hex geometry:
  - dx="72.95" (horizontal spacing between hex centers, in pixels)
  - dy="85.25" (vertical spacing between hex rows, in pixels)
  - sideways="true" (flat-top hex orientation, rows run horizontally)
  - Map image: 14310 x 4632 pixels

Zone definitions with pixel-boundary polygons and grid numbering offsets:

  Malta:   HexGrid x0=-15  y0=4    hOff=6   vOff=-1   stagger=false
  Map A:   HexGrid x0=55   y0=48   hOff=6   vOff=0    stagger=true
  Map B:   HexGrid x0=-16  y0=7    hOff=2   vOff=-33  stagger=false
  Map C:   HexGrid x0=-16  y0=10   hOff=12  vOff=-66  stagger=false
  Map D:   HexGrid x0=-16  y0=16   hOff=21  vOff=-99  stagger=false
  Map E:   HexGrid x0=-17  y0=-66  hOff=19  vOff=-133 stagger=false

Grid numbering:
  - first="H" (horizontal first)
  - hType="N" / vType="N" (numeric)
  - vDescend=true (rows count from top to bottom)
  - hDescend=false (columns count left to right)
  - sep="" (no separator between row/col in hex names)

Holding Boxes: Sicily, Italy, Benghazi, Derna, Crete, Bardia, Tobruk,
  Alexandria (hex 3613), Alexandria (hex 3714)
Off-map boxes: Tunis, Gabes, Tripoli, Tripolitania, plus rail-link boxes

CRITICAL DIMENSIONS FROM TCFNA CODE:
-------------------------------------
  MAX_COLUMNS = 166  (total columns across all 5 boards)
  MAX_ROWS    = 63   (total rows)

  Board A: columns 1-33    (section offset: +0)
  Board B: columns 34-66   (section offset: +33)
  Board C: columns 67-99   (section offset: +66)
  Board D: columns 100-132 (section offset: +99)
  Board E: columns 133-166 (section offset: +132)

  Each board section has up to 33 columns and ~47 rows of playable hexes.
  The full board is 166 columns x 63 rows.

HEX ID FORMAT (from CSV):
  BRRCC where:
    B  = board number (1=A, 2=B, 3=C, 4=D, 5=E)
    RR = row (01-47ish, zero-padded)
    CC = column (01-33ish per section, zero-padded)

  Converted to global ID: "%02d%03d" % (row, global_column)
  Label format: "A0101", "B0101", "C3102", etc.

10 TERRAIN TYPES:
  0=Clear, 1=Delta, 2=Desert, 3=Heavy Vegetation, 4=Mountain,
  5=Rock/Gravel, 6=Rough, 7=Salt Marsh, 8=Sea, 9=Swamp

3 HABITATION TYPES:
  0=None, 1=Oasis, 2=Village/Bir, 3=Major City

33 TERRAIN FEATURES (from Terrain struct):
  Airfield, Border, Clear, Coast, Delta, Desert, Escarpment,
  Flying Boat Alighting Area, Flying Boat Basin, Heavy Vegetation,
  Major City, Major River, Minor River, Mountain, Off Map Airfield,
  Off Map Flying Boat Basin, Oasis, Port, Railroad, Ridge, Road,
  Rock/Gravel, Rough, Salt Marsh, Sea, Slope, Swamp, Track,
  Training Area, Unfinished Railroad, Unfinished Road, Village/Bir, Wadi

HEXSIDE DATA (per hex, 6 directions: NE, E, SE, SW, W, NW):
  Elevation: 1-DnEsc, 2-DnSlp, 3-Ridge, 4-UpEsc, 5-UpSlp
  Trans (transport): 1-Track, 2-Road, 3-RR (Railroad), 4-UnfRd, 5-UnfRR, 6-Rd&RR
  Water: 1-Wadi, 2-SeaHS, 3-River, 4-Nile, 5-Border

CSV HEADER COLUMNS (28+1 columns):
  HexID, Map Hex, Hex Column, Hex Row, Hex RRCCC, Name, Terrain,
  Habitation, Misc, hsElevation NE/E/SE/SW/W/NW, (blank),
  hsTrans NE/E/SE/SW/W/NW, hsWater NE/E/SE/SW/W/NW
